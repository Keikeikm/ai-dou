# 斗地主积分规则

积分仅为本地游戏记录，不涉及现金、下注或兑换。

单份分数 = 底分 × 叫分 × 2^(炸弹数 + 火箭数) × 春天倍数。底分默认 1，叫分为 1、2 或 3；发生春天或反春天时春天倍数为 2，否则为 1。

地主获胜时获得两份分数，每位农民失去一份；农民获胜时每位农民获得一份，地主失去两份。每局三人的积分变化总和为零。

地主获胜且农民均未出过牌为春天。农民获胜且地主只出过一次牌为反春天。

仅正常完成的牌局结算；放弃或未完成的牌局不计分。同一局只结算一次，存储失败时允许重试，避免重复入账。记录默认保存在 data/ai-dou.sqlite，可使用 SCORE_DB_PATH 指定数据库路径。

吹牛第一版仅显示本局胜负，不接入斗地主积分系统。
