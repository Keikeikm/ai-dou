# 斗地主观战与回放

首页选择斗地主的「AI对战」创建房间，在房间中开始、暂停或逐步推进。房间地址为 /rooms/:roomId；设置中的观战链接可以分享给能访问该本地服务的人。

观战时可点击手牌调整当前浏览器的翻面显示。显示偏好只影响当前观众，不影响其他观众或模型输入。真人对战的操控界面在游戏结束前隐藏对手手牌。

出牌记录提供历史步数与模型返回；回看历史不会暂停共享牌局，可选择返回实时。完成结算的牌局可从记录中进入 /games/:gameId 回放，或导出日志。

房间与实时状态保存在内存，重启服务后需重新建房；斗地主和吹牛已提交的动作会持续写入数据库，中断后的记录可在数据中心查看。斗地主积分仍按正常完成的牌局结算。吹牛为私有双人房间，不提供观战链接。
