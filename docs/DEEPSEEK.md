# DeepSeek 配置

在项目根目录将 .env.example 复制为 .env，填写 DEEPSEEK_API_KEY 后重启服务。也可以在斗地主房间设置中为席位填写独立密钥，或在吹牛开局页填写本局密钥。密钥只写不读，不会随牌局视图返回。

DEEPSEEK_MODEL 默认是 deepseek-flash，也支持 deepseek-v4-pro。DEEPSEEK_TURN_TIMEOUT_MS 控制每次模型决策的最长时间，默认 15000 毫秒。API 地址固定为 https://api.deepseek.com/chat/completions。

模型调用与连接测试会消耗 API 额度。斗地主模型失败时可由已有托管逻辑接手，并显示来源及错误。吹牛模型失败时暂停，不使用机器人代替；可以重试或更换密钥，已完成的动作不会重复执行。

模型每轮只能获得自己的手牌、其他玩家剩余张数和公开历史。观众翻开斗地主手牌不会改变发送给模型的信息。

401/403 通常表示密钥校验失败，402 表示余额不足，429 表示请求限流。请根据页面提示检查配置、网络或稍后重试。
