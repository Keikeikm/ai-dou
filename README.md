# AI DOU

AI DOU 是一个在本机浏览器运行的 AI 棋牌室。首页可选择 **斗地主** 或 **吹牛**：斗地主保留三个 AI 观战、真人与两个 AI 同桌、回放、积分与复盘分析；吹牛是你与 **DeepSeek 鲸鱼娘** 的双人心理博弈。独立的 **数据中心** 使用 [AntV AVA](https://github.com/antvis/AVA) 分析多局走势与玩家习惯，并保留可供后续训练的动作档案。

角色素材来源见 [头像来源说明](client/public/avatars/README.md)。

## 下载安装

1. 安装 [Node.js](https://nodejs.org/) 22.13 或更新版本。
2. 在 [GitHub 仓库](https://github.com/Keikeikm/ai-dou) 点击 **Code → Download ZIP**，下载并解压；也可使用 Git：

   ```bash
   git clone https://github.com/Keikeikm/ai-dou.git
   ```

3. 在项目目录打开终端，安装依赖并启动：

   ```bash
   npm ci
   npm run ui
   ```

打开终端显示的地址（默认 [http://127.0.0.1:5173](http://127.0.0.1:5173)），即可在大厅选择游戏。

内置 Bot 无需密钥。使用 DeepSeek 时，启动前将 `.env.example` 复制为 `.env`，填写 `DEEPSEEK_API_KEY`；模型对战和复盘问答会消耗 API 额度。

## 与鲸鱼娘玩吹牛

进入首页的「和鲸鱼娘吹牛」，使用服务端已有的 DeepSeek 密钥，或在开局页输入自己的 API key。点击开始后你先出牌；鲸鱼娘通过 DeepSeek API 判断是否质疑并选择自己的出牌。页面中的角色台词为界面文案，实际出牌与质疑由模型决定。没有密钥时不会以 Bot 冒充模型；请求失败时暂停，可重试或更换密钥。

采用顺序点数的双人吹牛玩法，并约定质疑赢家出下一手：

- 52 张牌，无大小王，每人 26 张，按 A → 2 → … → K → A 循环声称。
- 每次盖下 1–4 张任意手牌，声称全是本轮点数，允许撒谎或混牌。
- 对方可相信或质疑。质疑只翻最近一手，撒谎者收走整个牌堆；说真话则质疑者收走整个牌堆。相信时不翻牌，牌堆保留。
- 质疑成功：说谎者收牌，质疑者出下一手。质疑失败：质疑者收牌，说真话的出牌者继续。相信后由回应者出牌。无论谁出下一手，点数照常前进。
- 翻牌后确认结果才进入下一手，AI 不会在翻牌动画期间提前出牌。刷新时未确认的结果仍可继续。
- 最后一手必须被相信或经质疑证实为真才能获胜。

实时房间保存在服务端内存；同一标签页刷新可继续，闲置一小时后过期，服务重启后需要重新开局。已提交的动作持续保存到数据库，关闭或中断后仍可在数据中心回看。返回大厅按钮会关闭吹牛房间。API key 不写入浏览器存储或牌局日志；浏览器会话仅保存席位令牌。模型和浏览器分别只获取自己的手牌与公开信息。

## 数据中心

从首页进入「打过的牌，都算数」，按游戏、玩家、日期和完成状态筛选。AVA 自动推荐多局图表、检测数据规律，风格表展示吹牛率、质疑成功率或斗地主出牌习惯。分析在本地运行，不消耗模型 API 额度。牌局列表支持单局逐步回看，局内不自动展示分析面板。

数据默认长期保存在 `data/ai-dou.sqlite`（可用 `SCORE_DB_PATH` 更改）。创建固定玩家档案后，未来新房间的操作会归到同一个人。已有斗地主结算记录自动导入；旧版本已丢失的吹牛内存记录无法恢复。

新的吹牛牌局使用 `bluff-winner-leads-52-v2`；已有 v1 档案仍按旧规则复盘和导出，不会改写历史出牌顺序。

可按当前筛选条件导出完整档案或决策样本 JSONL。后者只重建行动者可见的信息，标注动作来源、胜负、截断和按局划分的数据集，方便后续行为克隆或强化学习。数据格式、指标口径与备份方法见 [数据说明](docs/DATA.md)。第一版不包含训练器或已训练的风格模型。

## 开发

```bash
npm run dev     # 服务端与前端热更新
npm test        # 规则、接口、前端回归测试
npm run build  # 类型检查与生产构建
npm start      # 运行已构建版本
```

吹牛模块独立于斗地主：`shared/bluff.ts` 定义动作与观测，`server/bluff/game.ts` 裁决规则，`server/bluff/agent.ts` 实现决策接口，`server/bluff/rooms.ts` 管理生命周期与模型请求。`client/components/BluffGame.tsx` 提供开局、牌桌及规则说明。新增决策实现只需接收私有观测并返回合法动作，不需要更改规则引擎。
